## Exact locked dependency relationships

- Adapter `2.11.3` declares peer `@prisma/client >=2.26.0 || >=3 || >=4 || >=5 || >=6` and dependency `@auth/core 0.41.3`.
- NextAuth `5.0.0-beta.25` depends on `@auth/core 0.37.2` and accepts Next `^14.0.0-0 || ^15.0.0-0`.
- The project locks Prisma Client `6.19.3`, Next `15.5.27`, adapter `2.11.3`, and NextAuth beta.25. The Prisma peer and Next peer are met; the duplicate Auth core versions leave integration type compatibility **Unverified**.
- Neither adapter package metadata nor reviewed source declares a separate Node engine; runtime floor is inherited from Prisma/Next dependencies.
