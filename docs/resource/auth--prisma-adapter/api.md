# Verified API Surface

`@auth/prisma-adapter@2.11.3` has one package export: `PrismaAdapter`. It accepts a Prisma Client and returns an Auth.js `Adapter` object implementing 19 methods. The database operation details below are read from the exact tagged implementation; method argument/return contracts are from its matching `@auth/core@0.41.3` adapter interface.
