# Verified API Surface (`next@15.5.27`)

Comprehensive verified practical API surface for Next.js 15.5.27 focusing on App Router, Server Actions, Route Handlers, and core navigation/utility hooks.

| API / Module | Signature & Options | Description & Return Values | Evidence |
|---|---|---|---|
| `next/navigation` (`redirect`) | `redirect(url: string, type?: RedirectType): never` | Server-side navigation helper (throws `NEXT_REDIRECT` error; call outside try/catch). | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/functions/redirect) |
| `next/navigation` (`useRouter`) | `const router = useRouter()` | Client-side router hook (`push`, `replace`, `refresh`, `back`, `forward`, `prefetch`). | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/functions/use-router) |
| `next/navigation` (`usePathname`, `useSearchParams`) | `const pathname = usePathname(); const searchParams = useSearchParams()` | Client hooks for current path and URL search parameters. | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/functions/use-pathname) |
| `next/headers` (`headers`, `cookies`) | `const hdr = await headers(); const cks = await cookies()` | Next.js 15 asynchronous request headers and cookies accessors (must be awaited). | [Web] [Next.js 15 Upgrade Guide](https://nextjs.org/docs/app/building-your-application/upgrading/version-15) |
| `next/cache` (`revalidatePath`, `revalidateTag`) | `revalidatePath(path: string, type?: 'page' \| 'layout'); revalidateTag(tag: string)` | Purge cached Server Actions / Data cache entries on-demand. | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/functions/revalidatePath) |
| `next/cache` (`unstable_cache`) | `unstable_cache(fn, keyParts?, options?)` | Memoizes data fetching function across requests with tag/revalidation support. | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/functions/unstable_cache) |
| `next/link` (`Link`) | `<Link href="..." prefetch={true \| false}>...</Link>` | Client-side navigation component with automatic prefetching in viewport. | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/components/link) |
| `next/image` (`Image`) | `<Image src="..." alt="..." width={n} height={n} priority={bool} />` | Optimized image component with automatic sizing, modern formats (WebP/AVIF), and lazy loading. | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/components/image) |
| Server Actions (`"use server"`) | `async function myAction(formData: FormData)` | Functions executed on server, invokable from client or server components; supports progressive enhancement. | [Web] [Next.js Docs](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations) |
| Dynamic Routes (`params`, `searchParams`) | `export default async function Page({ params, searchParams }: { params: Promise<{ id: string }>, searchParams: Promise<{ [key: string]: string \| string[] \| undefined }> })` | In Next.js 15, `params` and `searchParams` are Promises and must be `await`ed in Server Components and Route Handlers. | [Web] [Next.js 15 Upgrade Guide](https://nextjs.org/docs/app/building-your-application/upgrading/version-15) |
| Route Handlers (`GET`, `POST`, etc.) | `export async function GET(request: NextRequest, { params }: { params: Promise<{ ... }> })` | Web Request/Response API handlers for custom endpoints under `app/api/.../route.ts`. | [Web] [Next.js Docs](https://nextjs.org/docs/app/building-your-application/routing/route-handlers) |
| `next/font/google` | `import { Geist } from "next/font/google"; const geist = Geist({ subsets: ["latin"] })` | Zero-layout-shift self-hosted Google font loader. | [Web] [Next.js Docs](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) |
| `next/error` / `not-found` | `notFound()` | Triggers HTTP 404 response boundary (throws `NEXT_NOT_FOUND`). | [Web] [Next.js Docs](https://nextjs.org/docs/app/api-reference/functions/not-found) |
