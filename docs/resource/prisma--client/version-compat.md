## Runtime boundary

The project's schema uses `provider = "postgresql"` and generator `prisma-client-js` with custom output `../generated/prisma`. The documented standard path is Node.js. Prisma ORM v6 offers Rust-free `engineType = "client"` from 6.16 onward only when configured with a driver adapter; this project schema does not currently declare that setup, so do not assume edge compatibility from the v6 package export map alone. See [Prisma Client API reference, Rust-free mode](https://www.prisma.io/docs/orm/v6/reference/prisma-client-reference.md#prismaclient).
